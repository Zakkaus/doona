Added

- The group editor has an experimental Exit node field on honk. It offers the nodes a proxy chain can tunnel through, and writes the group's `exit` to the configuration. A group's details show its exit.
- A subscription whose refresh honk rejected because a proxy chain hop or group exit would name a removed or duplicated node says so beside its status, and that the previous nodes stay in use.
- honk's group exit diagnostics read in the page language where a configuration write is refused.
