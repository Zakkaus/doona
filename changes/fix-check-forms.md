Fixed

- Typing a number below a field's minimum on the way to a valid one, such as 128 in a field from 64, keeps the typing instead of snapping it to the minimum; whole-number fields no longer take a decimal point.
- A page that replaces its Skeleton twice in quick succession keeps its scroll height until the latest swap settles.
- Enter in the profile name, custom geodata URL, rule condition and expression, quick rule and routing template dialogs does what the dialog's main button does.
- A global setting no longer swaps between a number field and a text field, and loses focus, while it is edited.
- Copying on a plain-HTTP address returns keyboard focus to the control that copied.
