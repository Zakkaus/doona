# 主题与配色

## 配色

十五套配色各有浅色与深色。Rosé Pine 有两种，Catppuccin 有三种，玻璃有四种；另外六种是 Nord、Kary Pro Colors、Ant Design、Arco Design、Semi Design 与中国。中国配色的两种模式是白班与夜班。

玻璃系列是叠在壁纸上的材质。玻璃遵循 Apple 的 Liquid Glass，在 Chrome 与 Edge 中会让浮动面板、菜单与通知的边缘折射下方的页面。毛玻璃遵循 Microsoft 的 Acrylic，只透出颜色。浮层把顶栏改为内缩的独立图层，背景均匀模糊。着色遵循 Microsoft 的 Mica，表面接近不透明，不做模糊。系统开启“降低透明度”或“增强对比度”时，所有玻璃配色都改用不透明表面与清晰的边框。

中国配色将良好与运行中显示为稳中向好，将不可用与降级显示为严峻挑战。可在顶栏切换配色，或使用登录页的配色菜单。
