# 主題與配色

[English](themes.md) / [简体中文](themes.zh-CN.md) / 繁體中文

## 配色

十五套配色各有淺色與深色。Rosé Pine 有兩種，Catppuccin 有三種，玻璃有四種；其餘六種為 Nord、Kary Pro Colors、Ant Design、Arco Design、Semi Design 與中國。中國配色的兩種模式是白班與夜班。

玻璃系列是疊在桌布上的材質。液態玻璃依照 Apple 的 Liquid Glass，在 Chrome 與 Edge 中會讓浮動面板、選單與通知的邊緣折射下方的頁面。玻璃使用模糊與填色，不做折射；Firefox 與 Safari 中的液態玻璃也採用這種呈現方式。毛玻璃讓所有表面使用同一種均勻模糊，背後的形狀仍可隱約辨認。著色依照 Microsoft 的 Mica，表面接近不透明，不做模糊。系統開啟「降低透明度」或「增加對比」時，所有玻璃配色都改用不透明表面與清楚的邊框。

中國配色將良好與運作中顯示為穩中向好，將無法使用與降級顯示為嚴峻挑戰。可在頂欄切換配色，或使用登入頁的配色選單。

設定頁分為一般與外觀兩個分頁。配色選單末尾的外觀設定可開啟外觀分頁，選擇配色或自訂桌布。使用玻璃配色時，桌布也會顯示在登入卡片後方。
